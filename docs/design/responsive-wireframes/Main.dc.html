REVIV // Mid-fidelity web wireframes

One web app, three widths

Every screen is built once and reflows with the width it is given. Design mobile first; tablet and desktop add columns, never new features.

Primary

Mobile web

320–767 px · design at 390

  • 4 columns · 20 px margin · 16 gutter
  • Sticky header + bottom tab bar
  • One column, full-width buttons
  • Touch targets ≥ 44 px
Adapts

Tablet

768–1199 px · design at 834

  • 8 columns · 32 px margin · 20 gutter
  • Top web nav replaces the tab bar
  • Two columns where content pairs
  • Card grids go to 2 across
Adapts

Desktop

1200 px + · design at 1440

  • 12 columns · content max 1200 · 24 gutter
  • Top web nav, centred content
  • Sidebars for forms and panels
  • Card grids go to 3–4 across

What changes per width

  • Navigation: tab bar (mobile) → top nav with links (tablet, desktop)
  • Title size: 40 → 56 → 76 px (Oswald, uppercase)
  • Garment image sits above details on mobile, beside them wider
  • Recipe cards: 1 → 2 → 4 across
  • Closet rail shows 3 → 5 → 7 pieces

What never changes

  • Same features and copy at every width
  • Concept badge on every AI concept image
  • No prices, shop links or other brands
  • Primary action stays the first button
  • White canvas, steel type, one lime badge fill
